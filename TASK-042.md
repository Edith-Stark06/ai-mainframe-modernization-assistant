# TASK-042 — Java Compilation Tests

## Objective

Implement automated tests that compile the Java source generated by the compiler to verify that it is syntactically valid Java.

---

## Background

The compiler currently validates:

- Unit behavior
- End-to-end translation
- Regression scenarios
- Golden-file output

This task adds one more level of confidence by ensuring the generated Java code can be successfully compiled with the Java compiler.

---

# Scope

Create a Java compilation test suite that:

```
COBOL Source
      ↓
Compiler Pipeline
      ↓
Generated Java
      ↓
javac
      ↓
Compilation Result
```

---

# Functional Requirements

## 1. Create Compilation Test Structure

Create:

```
tests/compilation/
```

---

## 2. Fixture Discovery

Reuse existing COBOL fixtures where practical (for example, from `tests/golden/` or `tests/integration/`) instead of duplicating them.

Automatically discover fixtures.

---

## 3. Generate Java

For each fixture:

1. Execute the complete compiler pipeline.
2. Generate Java source.
3. Write the source to a temporary directory.

Do not modify repository files.

---

## 4. Compile Generated Java

Invoke the Java compiler (`javac`) on the generated source.

If Java is unavailable, skip the test with a clear pytest skip message rather than failing.

---

## 5. Assertions

For successful fixtures:

- Java compilation succeeds.
- Exit code is zero.
- No compiler errors.

For invalid COBOL fixtures:

- The compiler should stop before Java generation.
- `javac` should not be invoked.

---

## 6. Temporary Files

Use pytest temporary directories (`tmp_path` or equivalent).

Clean up automatically after execution.

---

## 7. Failure Reporting

On compilation failure, report:

- fixture name
- generated Java file path
- javac stderr
- javac stdout (if present)

---

## 8. Deterministic Execution

Running the tests multiple times should produce identical compilation results.

---
