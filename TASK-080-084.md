# Cross-Cutting Requirements

## Determinism

All generated:

- flows
- nodes
- edges
- scores
- recommendations
- API responses

must be deterministic.

No reliance on:

- memory addresses
- object identity
- unordered iteration
- `repr()` for ordering
- nondeterministic set ordering

---

## Immutability

Existing immutable domain models must remain immutable.

Do not mutate:

- analysis results
- IR structures
- Flow objects
- RAG results
- AI results

Caller-owned objects must not be modified.

---

## Serialization

All public domain/API models must be JSON serializable.

Verify using:

`json.dumps(...)`

Serialization must not leak:

- memory addresses
- object representations
- implementation-specific state
